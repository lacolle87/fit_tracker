# Fit tracker

Локальный трекер питания: данные хранятся в `fit.duckdb`, а продукты и приёмы пищи добавляются через CLI.

## Запуск

```powershell
python -m pip install -r requirements.txt
python fit_tracker.py init
python fit_tracker.py log "куриная грудка 200; рис вареный 150; овощи свежие 200"
python fit_tracker.py today
```

Количество указывается в граммах. Ввод можно повторять в течение дня — `today` пересчитает общий итог.

Добавить свой продукт (значения на 100 г):

```powershell
python fit_tracker.py add-food "Сыр" 350 25 28 0
```

Сохранить готовое блюдо (масса и БЖУ всей приготовленной партии):

```powershell
python fit_tracker.py add-dish "Курица с рисом" 350 525 66 8 42
python fit_tracker.py log-dish "Курица с рисом" 0.5
```

Формат `add-dish`: название, масса всей партии в граммах, затем её калории, белки, жиры и углеводы. При `log-dish ... 0.5` добавляется половина партии. Блюдо сохраняется в DuckDB и дальше пересчитывается локально.

Профиль и стартовые цели находятся в начале `fit_tracker.py`. Вес и замеры пока не меняют цели автоматически: это сделано намеренно, чтобы не создавать ложную точность. Для безопасной настройки под реальную активность цели лучше пересматривать по динамике веса за 2–3 недели.

Важно: цифры в базе ориентировочные; для фасованных продуктов используй этикетку, а для круп и макарон всегда уточняй, вес указан сухого или готового продукта.
